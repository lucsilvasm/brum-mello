# Estratégia

## Fase

Construção do site oficial do Brum & Mello. Identidade visual já definida
(ver `identidade/design-guide.md`); o trabalho agora é traduzir isso em uma
experiência digital premium.

## Prioridade principal

Site oficial — desenvolvido por partes, sob direção do Lucas, a partir dos
prints de referência que ele envia. Estrutura prevista no briefing:
hero → introdução → experiência → rodízio → gastronomia → vinhos → momentos →
tradição → números (só se houver dado real) → localização → reserva → footer.

CTA principal em todo o site: **RESERVAR MESA**.

## O que pode esperar

Tudo que não foi pedido. O ritmo é ditado pelo Lucas: ele manda referência,
a gente executa aquela parte, ele aprova, segue pra próxima.
